# Reporting a security issue

To report a suspected vulnerability, sign in to GitHub and use the project's private reporting form when available. Include the affected page or file, the version or commit if known, and what you observed. Remove credentials, personal data and private documents before submitting. [Open a private vulnerability report](https://github.com/Nsj08/origin-ksa-site/security/advisories/new)

If the private form is unavailable, keep the details confidential. The project has no working security mailbox at present. Public GitHub issues are for non-sensitive corrections to product information. Limit testing to systems you control or have permission to test, and avoid disrupting the site or accessing other people's data.
